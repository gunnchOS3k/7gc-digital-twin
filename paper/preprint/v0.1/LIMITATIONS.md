# Paper I limitations and threats to validity

Construct: stored bearer state and declared offline coverage are not independently validated application thresholds. Connected states receive target without correctness/deadline checks. A Bernoulli success is not an executed task.

Internal: the fixture taxonomy and stochastic device classes are different; their evidence is not calibrated or combined. Conditional pseudorandom draws and class order must remain fixed. Several secondary fields duplicate the same Boolean sequence. The outage-entry counter does not observe successful recovery.

External: 21 authored snapshots and30 seeds cannot establish general workload/hardware/community performance. Only wearable has an unsupported task; no degraded state is exercised. Twenty Gary context rows reuse snapshots and cannot estimate population failure risk.

Statistical: intervals are for Monte Carlo means under the fixed priors, not real populations or model-parameter uncertainty. The smartphone completion expectation is outside its unadjusted descriptive class interval; no formal goodness-of-fit conclusion is made. No paired controller test or effect size exists. Analytic and semantic audits are post hoc, and the four-seed history must not be recast as prospective30-seed registration.

Physical/numerical: abstract steps have no real duration. Latency, jitter, energy, loss and throughput are uncalibrated proxies; they do not support RF, battery, carrier, packet, fieldwork or human-experience claims.

Provenance/rights: semantic digest_match compares stored identifiers; the separate file SHA verifies retained bytes. The upstream profile source Git SHA and redistribution permissions remain unconfirmed. This AI-assisted audit is not independent human scientific approval. The accepted portable extraction used existing macOS dependencies, not a fresh platform.

Novelty/publication: the reproducible artifact and elementary characterization may remain too narrow for an IEEE journal. Prior service resilience, edge fallback, trace-driven benchmarks and network twins constrain claims. Human significance/originality, article/data licenses and public release remain pending.
