# Paper I author-review package

**Minimum-Useful-Service Continuity: A Reproducible Synthetic Benchmark and Metric-Semantics Audit for Edge Devices**. IEEE Access format, author review only. The canonical manuscript is `paper/manuscript.tex`, its section files and `paper/bibliography.bib`. `paper/scripts/package_submission.py` synchronizes the standalone submission source, sections, tables, figures and template assets; generated copies are not edited independently.

Start with `manuscript.pdf`, `PLAIN_LANGUAGE_SUMMARY.md` and `OWNER_REVIEW_WORKSHEET.md`. `REPRODUCIBILITY.md`, `DATA_DICTIONARY.md`, `SUPPLEMENTAL_METHODS.md`, `CLAIM_TO_EVIDENCE.md`, `CITATION_VERIFICATION.md`, `ILLUSTRATION_ACCESSIBILITY.md` and `QUALITY_GATES.json` supply the evidence and remaining gates. Original illustrations are scripted in `paper/scripts/build_owner_review.py`; PDF/SVG/PNG exports are in figures. All 31 book chapters and the WAIKE curriculum remain external canonical content rather than duplicated in this package.

This is a synthetic benchmark and semantic audit. The class ordering follows configured priors; there is no calibrated hardware comparison, sensor-updated physical twin, packet-level RAN, actual workload execution or independent policy contest. Human scientific/editorial review, rights declarations, novelty judgment and any release/submission authorization remain pending.
